# 交互体验修正

2026-11-01，基于 v7 面板像素捕获修复后的工作树。用户要求统一选择控件、提前准备 Codex、用滑块调整推理强度、人工浏览不中断 AI 工作，并以美元作为用量页首单位。用户进一步明确同意显示可核实的 API 等价估算。

## 界面

- 可见的原生选择控件统一为 HeroUI Select，包括模型、页面缩放、操作记录、元素查找、元素动效、共享设置和用量筛选。库内隐藏的辅助表单元素及浏览器键盘输入接收器保留。
- 模型选择位于输入栏附近的锚定浮层，取消居中遮罩弹窗；推理强度使用离散刻度滑块，选项仍来自本机模型目录。键盘、默认恢复、忙碌禁用、保存失败和目录失效均有相应状态。
- 未明确选择模型时显示“默认模型”，不把 `model/list` 中的目录默认项冒充当前 CLI 配置。选择后的配置仍只作用于下一轮任务。
- 顶部 Codex 状态区分“已登录”“初始化中”“已就绪”“连接失败”。已登录不再等同于执行连接已经初始化。

## 连接与人工协作

启动、新建和选中对话时提前准备 Codex 执行会话，合并并发初始化；预热不发送模型轮次。模型目录和实际任务复用已准备的进程/会话。工作目录、可执行文件、工具定义变化或进程退出会按真实状态刷新，正在执行的会话不会被历史对话预热替换。

普通鼠标、滚轮和键盘输入不再调用整轮 `stopTurn`。人工操作使旧页面观察与排队动作失效，AI 重新观察后可以继续。若 Neo 调用在途，取消该原生会话以释放人工输入队列，下一次观察重新建立原生会话；只读等待不产生“未知写入”屏障。对可能已经写入的动作，仍需以新观察和证据检查点核对结果，避免重复提交。显式“停止任务”、共享控制权、旧坐标与授权检查保留。

相关入口：`main.ts` 的会话准备与派发、`agents.ts` 的 `prepare()`、`neo-browser.ts` 的人工交互处理；UI 使用 `conversation:prepare`、`codex:state` 和 `AppSnapshot.codexConnection`。协议初始化依据为 [OpenAI App Server 文档](https://learn.chatgpt.com/docs/app-server)。

## 美元口径

首指标、每日图表、费用分项和明细首金额列为 **API 等价估算（USD）**，Token 保留为次级数据。费率来自 [OpenAI 官方 API 价格](https://developers.openai.com/api/docs/pricing)，当前核验日期为 2026-11-01，覆盖本机五个模型。

估算采用明确的 Standard、短上下文、30 分钟缓存写入基准，不推断订阅实际扣费、速度档、单请求长上下文或附加费。输入拆为普通输入、缓存读取和缓存写入，输出包含推理，不重复计费。未知模型、混合模型、缺失字段保留未知或部分；没有证据的费用不显示为零。

每条可估算记录保存模型、币种、计价单位、来源、核验日期及费率快照。旧记录有真实用量时可按本次核验基准计算等价值，不将其描述为历史账单。缺少费率时，已有 Token 数仍可查看。

## 验收入口

- `tests/interaction-controls.e2e.ts`：隔离 UI，目录预加载、滑块键盘、默认恢复、错误回滚、未知/失效选项、焦点、375px 布局、减少动态效果。
- `tests/interaction-lifecycle.e2e.ts`：真实 Electron/Neo 与确定性 CLI 夹具，核对发送前初始化、连续对话复用、人工输入不取消整轮和显式停止。夹具不消耗模型配额。
- `tests/interaction-live.e2e.ts`：真实 Codex 与本地页面，等待期间人工滚动/点击、重新观察并完成填写、后续轮次连接复用及真实用量估算。
- `tests/complex-native.test.ts`：原生长只读等待及时释放输入；在途写入取消、未知结果核对与恢复；保留既有复杂工作流边界。
- `tests/usage-pricing.test.ts`、`tests/usage.test.ts`、`tests/usage-currency-ui.e2e.ts`：计价、缺失数据、快照、重启、筛选、分组与窄面板。
- 原有帧展示、视口缩放和工作区交互回归继续使用真实网页控件，选择动作已迁移至自绘菜单。

本轮修改前副本位于 `.runtime/interaction-refinement/before/`。证据位于 `test-results/interaction-refinement/`，美元独立 UI 截图另在 `test-results/interaction-refresh/usage/`。测试仅使用隔离本地页面和数据目录，没有替换凭据或改写用户站点内容；未提交、推送或部署公网。

## 本机结果

- 最终单元套件 187 通过、16 个需要原生环境的项目跳过；类型检查通过。
- 独立选择器 UI 8 项、美元 UI 6 项、帧展示 4 项、视口坐标 6 项、工作台交互 10 项均通过。共享双方通过 HTTPS/WSS loopback 加入，使用新权限选择器后能实际操作同一页面。
- 5 秒原生只读等待的红测试确认人工输入被堵塞；修复后滚动 240px 在 39ms 内到位，点击在 26ms 内生效。旧复杂工作流与未知写操作核对屏障回归通过。
- 真实 Codex：发送前约 7.1 秒进入 ready，执行线程已有 ID、尚无模型轮次。等待页面时，人工滚动 140px 和点击一并在约 159ms 内读回，任务仍在执行；AI 随后重新观察、完成填写并建立证据检查点。刷新目录及两轮任务期间新增 Codex worker 数为 0。真实返回用量已显示美元估算。
- 受控 CLI 整体验收另外确认显式停止仍发出 interrupt，新对话在第一条消息之前准备就绪；它与真实模型验收分开记录。

独立构建为 `release/interaction-refinement/mac-arm64/Athena.app`，名称和版本仍为 Athena 0.6.0，ad-hoc 深度签名校验通过，未公证。包内 13 个构建文件与已测试的 `dist` 文件逐个 SHA-256 一致，见 `package-integrity.json`。上述时延为本机有限样本，不代表所有站点或长期负载。

新包的受控 CLI 整体验收再次通过。随后正常退出空闲旧版，使用原数据目录打开新包；已在实际窗口核对新 `app.asar` 路径、Codex“已就绪”和原有 GPT-6.1-Sol／深度选项的滑块。窗口已置前，未发送用户任务。最终汇总为 `test-results/interaction-refinement/verification.json`。
