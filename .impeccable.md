## Design Context

### Users

Athena helps people work with local AI agents on conversations, code and webpages. First-use setup should be understandable without prior knowledge of CLI protocols, and project-free conversations must be possible.

### Brand Personality

Calm, capable and personal. The user should feel they are starting a collaboration with Athena, with clear control over installation, login and actual tasks.

### Aesthetic Direction

Use the existing monochrome surfaces, official Athena portrait and colored agent marks. The welcome experience takes its restrained pacing and spatial continuity from Apple's first-use interfaces: a large brand introduction becomes a compact conversation, then opens into the workspace. Support light/dark themes and reduced motion.

### Design Principles

- Keep choices and their resulting user messages spatially connected.
- Reveal short phrases and complete thoughts; avoid character-by-character typing effects.
- Let actual host results advance setup; animation never proves installation or login.
- Keep project selection optional and preserve the user's existing work and history.
- Finish with the real, interactive Athena welcome page in the browser workspace.
